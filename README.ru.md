# AngleFeint

Мой личный сайт и независимый блог.

Я пишу о технологиях, ИИ, истории, местах, играх, политике и о том, что замечаю по пути.

> Впереди нас ждёт ещё более широкий мир.

[Открыть AngleFeint](https://anglefeint.com)

## Технологии

Сайт создан с помощью [Astro](https://astro.build/) · [Anglefeint Theme](https://github.com/anglefeint/astro-theme-anglefeint).

## Разработка

Требуется Node.js 22.12.0 или новее.

```bash
npm ci
npm run dev
```
