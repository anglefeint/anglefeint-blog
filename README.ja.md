# 観察と記録

[Astro](https://astro.build/) の [Anglefeint](https://github.com/anglefeint/astro-theme-anglefeint) テーマを使った個人のメモとエッセイです。

**既定ロケール（5 言語）：** `en` · `ja` · `ko` · `es` · `zh`

## このサイトについて

世界、創造、AI、人間、組織についての観察と記録。

## ローカル開発

Node.js 22.12 以上が必要です。

```bash
npm install
npm run dev
```

ビルドとプレビュー：

```bash
npm run build
npm run preview
```

サイト設定と各言語の文言は `src/site.config.ts`。デプロイ時は `PUBLIC_SITE_URL` や `PUBLIC_SITE_TITLE` などで上書きできます。
