# AngleFeint

私の個人サイト兼インディペンデントブログです。

技術、AI、歴史、場所、ゲーム、政治、そして日々の発見について書いています。

> もっと広い世界が、まだ待っている。

[AngleFeint を訪れる](https://anglefeint.com)

## 使用技術

このサイトは次の技術で構築しています： [Astro](https://astro.build/) · [Anglefeint Theme](https://github.com/anglefeint/astro-theme-anglefeint).

## ローカル開発

Node.js 22.12.0 以降が必要です。

```bash
npm ci
npm run dev
```
