海外向けのビジネスをするようになってから、中国のことはあまり追わなくなった。最近、中国にいる友人から、今は中国の SIM カードをスマホに挿したままでも、VPN さえ使えば中国で TikTok を見られると聞いて、かなり驚いた。

中国にいた頃から知っていたけど、TikTok は IP アドレスを確認するだけじゃない。SIM カードの通信事業者や地域の情報も読み取る。VPN を使っていても、中国の SIM だとわかれば、やっぱり使わせてもらえなかった。

友人によると、Apple が数年前に iOS を変更したからだという。新しい SDK でビルドしたアプリは、従来の API から実際の通信事業者情報を取得できなくなり、固定のダミー値しか返ってこなくなった。だから TikTok も、その API では SIM カードの本当の地域情報を読み取れなくなったそうだ。

Android はいつ追いつくんだろう。今も SIM カードの国や通信事業者を読み取る API がある。もっとも、Android はオープンソースだから、将来 Google が制限しても、メーカーは自社のシステムにその API を残したり、別の API を追加したりすることが技術的にはできる。それでも Android が提供をやめれば、少なくとも悪いことをするコストは一段上がる。Google のあの言葉、“Don't be evil” を思い出す。

だから、私の TikTok に対する見方は、中国共産党に対する見方と同じだ。そもそも TikTok 自体が共産党の意思を代表しているわけで、中国のユーザーに課しているこうした制限も、国内外の情報を隔てようとする共産党の意思を実行しているということだ。

もしある日、彼らがいいことをしていると気づいたら、それはたぶん、そうせざるを得なかったからだ。自分から進んでいいことをすることは決してない。
