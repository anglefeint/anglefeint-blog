# AngleFeint

我的个人网站与独立博客。

我在这里记录关于技术、AI、历史、地方、游戏、政治的思考，以及沿途的见闻。

> 更广阔的世界，仍在前方。

[访问 AngleFeint](https://anglefeint.com)

## 致谢

本站使用 [Astro](https://astro.build/) · [Anglefeint Theme](https://github.com/anglefeint/astro-theme-anglefeint).

## 本地开发

需要 Node.js 22.12.0 或更高版本。

```bash
npm ci
npm run dev
```
