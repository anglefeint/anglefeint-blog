# 观察与记录

个人笔记与文章站点，基于 [Anglefeint](https://github.com/anglefeint/astro-theme-anglefeint) Astro 主题。

**默认语言（5 种）：** `en` · `ja` · `ko` · `es` · `zh`

## 关于本站

关于世界、创造、AI、人类与组织的观察与记录。

## 本地开发

需要 Node.js 22.12 及以上。

```bash
npm install
npm run dev
```

构建与预览：

```bash
npm run build
npm run preview
```

站点与多语言文案在 `src/site.config.ts`。部署时可用 `PUBLIC_SITE_URL`、`PUBLIC_SITE_TITLE` 等环境变量覆盖。
