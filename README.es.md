# Observaciones y notas

Notas y ensayos personales, construidos con el tema Astro [Anglefeint](https://github.com/anglefeint/astro-theme-anglefeint).

**Idiomas por defecto (5):** `en` · `ja` · `ko` · `es` · `zh`

## Acerca de este sitio

Observaciones y notas sobre el mundo, la creación, la inteligencia artificial, la humanidad y las organizaciones.

## Desarrollo local

Requisitos: Node.js 22.12 o superior.

```bash
npm install
npm run dev
```

Compilar y previsualizar:

```bash
npm run build
npm run preview
```

La identidad del sitio y los textos por idioma están en `src/site.config.ts`. En despliegue puedes usar variables `PUBLIC_SITE_URL`, `PUBLIC_SITE_TITLE`, etc.
