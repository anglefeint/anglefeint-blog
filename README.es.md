# AngleFeint

Mi sitio web personal y blog independiente.

Escribo sobre tecnología, IA, historia, lugares, videojuegos, política y lo que voy descubriendo por el camino.

> Un mundo más amplio aún nos espera.

[Visitar AngleFeint](https://anglefeint.com)

## Tecnologías

Este sitio está construido con [Astro](https://astro.build/) · [Anglefeint Theme](https://github.com/anglefeint/astro-theme-anglefeint).

## Desarrollo

Requiere Node.js 22.12.0 o posterior.

```bash
npm ci
npm run dev
```
