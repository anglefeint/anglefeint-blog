# AngleFeint

我的個人網站與獨立部落格。

我在這裡記錄關於技術、AI、歷史、地方、遊戲、政治的思考，以及沿途的見聞。

> 更廣闊的世界，仍在前方。

[造訪 AngleFeint](https://anglefeint.com)

## 致謝

本站使用 [Astro](https://astro.build/) · [Anglefeint Theme](https://github.com/anglefeint/astro-theme-anglefeint).

## 本機開發

需要 Node.js 22.12.0 或更新版本。

```bash
npm ci
npm run dev
```
