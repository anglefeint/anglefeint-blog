# AngleFeint

My personal website and independent blog.

I write about technology, AI, history, places, games, politics, and things I notice along the way.

> A wider world still awaits.

[Visit AngleFeint](https://anglefeint.com)

## Built With

Built with [Astro](https://astro.build/) · [Anglefeint Theme](https://github.com/anglefeint/astro-theme-anglefeint).

## Development

Requires Node.js 22.12.0 or later.

```bash
npm ci
npm run dev
```
