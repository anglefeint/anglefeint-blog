## Local development

Requirements: Node.js 22.12+.

```bash
npm install
npm run dev
```

Build and preview:

```bash
npm run build
npm run preview
```

Site identity and per-locale copy live in `src/site.config.ts`. Use `PUBLIC_SITE_URL`, `PUBLIC_SITE_TITLE`, and related `PUBLIC_*` variables to override defaults for deployment.
