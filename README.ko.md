# AngleFeint

저의 개인 웹사이트이자 독립 블로그입니다.

기술, AI, 역사, 장소, 게임, 정치, 그리고 살아가며 발견하는 것들에 관해 씁니다.

> 더 넓은 세상이 아직 기다리고 있습니다.

[AngleFeint 방문하기](https://anglefeint.com)

## 사용 기술

이 사이트를 만든 기술: [Astro](https://astro.build/) · [Anglefeint Theme](https://github.com/anglefeint/astro-theme-anglefeint).

## 로컬 개발

Node.js 22.12.0 이상이 필요합니다.

```bash
npm ci
npm run dev
```
