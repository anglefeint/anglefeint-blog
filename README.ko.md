# 관찰과 기록

[Astro](https://astro.build/) [Anglefeint](https://github.com/anglefeint/astro-theme-anglefeint) 테마로 만든 개인 메모와 에세이입니다.

**기본 로케일(5개):** `en` · `ja` · `ko` · `es` · `zh`

## 이 사이트에 대해

세계, 창조, AI, 인류, 조직에 대한 관찰과 기록.

## 로컬 개발

필요: Node.js 22.12 이상.

```bash
npm install
npm run dev
```

빌드 및 미리보기:

```bash
npm run build
npm run preview
```

사이트 설정과 언어별 문구는 `src/site.config.ts`에 있습니다. 배포 시 `PUBLIC_SITE_URL`, `PUBLIC_SITE_TITLE` 등으로 덮어쓸 수 있습니다.
