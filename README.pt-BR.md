# AngleFeint

Meu site pessoal e blog independente.

Escrevo sobre tecnologia, IA, história, lugares, jogos, política e coisas que observo pelo caminho.

> Um mundo mais amplo ainda nos espera.

[Visitar AngleFeint](https://anglefeint.com)

## Tecnologias

Este site é feito com [Astro](https://astro.build/) · [Anglefeint Theme](https://github.com/anglefeint/astro-theme-anglefeint).

## Desenvolvimento

Requer Node.js 22.12.0 ou superior.

```bash
npm ci
npm run dev
```
