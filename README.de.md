# AngleFeint

Meine persönliche Website und mein unabhängiger Blog.

Ich schreibe über Technologie, KI, Geschichte, Orte, Spiele, Politik und Dinge, die mir unterwegs auffallen.

> Eine weitere Welt wartet noch auf uns.

[AngleFeint besuchen](https://anglefeint.com)

## Technik

Diese Website basiert auf [Astro](https://astro.build/) · [Anglefeint Theme](https://github.com/anglefeint/astro-theme-anglefeint).

## Entwicklung

Erfordert Node.js 22.12.0 oder neuer.

```bash
npm ci
npm run dev
```
